MUG-Serve

Marginal-utility gating for medical question answering

Retrieved passages can pull a language model away from a correct answer. MUG asks the model first, then keeps the evidence only if it moves the answer, and optionally only if a verifier finds a quote that supports the new one.

How it works

1Answer closed-bookThe model answers with no evidence.
2Answer with evidenceThe same model answers again with retrieved textbook and PubMed passages.
3GateIf the answer did not move, the evidence is dropped. If it moved, the evidence is kept, or first checked for a supporting quote.

Every step is traced: what was retrieved, whether it moved the answer, what was kept, and what each call cost.

What you can do with it

  • Audit an existing RAG system. Put the proxy in front of its model calls in shadow mode. Answers are unchanged; each request is labelled no effect, moved + supported, or moved, no quote found.
  • Compare retrieval policies offline on a frozen set of documents: accuracy, tokens and latency.
  • Trim noisy retrieval. In our setup the gate matched naive RAG's accuracy with 5–9% of its evidence tokens.
  • Inspect one answer step by step in the UI.
  • Save cost with a strong model: a cheap scout decides whether evidence matters before the expensive model reads it.
  • Bring your own model: OpenAI, Anthropic, or GitHub Copilot.

Limits

  • Not a correctness check. "No effect" does not endorse the answer, and "supported" is an LLM judgement.
  • Misleading evidence that argues plausibly for a wrong answer can fool both the gate and the verifier.
  • Background passages (textbook-style) often contain no quotable support.
  • Model-dependent: with claude-haiku-4.5 the gate scored below the no-evidence answer on MedQA.
  • Slower than naive RAG, since it makes extra model calls.

Run it yourself

git clone https://github.com/PKM100/mug && cd mug
docker build -t mug .
docker run --rm -v mug-data:/data mug python ../scripts/download_index.py --data-dir /data  # optional, ~20 min
docker run --rm -p 127.0.0.1:8000:8000 -v mug-data:/data -e OPENAI_API_KEY mug            # http://127.0.0.1:8000

Use -e ANTHROPIC_API_KEY for Claude or -e GITHUB_TOKEN for GitHub Copilot. See the setup guide.
